# OpenAPI Schema

Этот каталог содержит типы, сгенерированные `openapi-typescript` из двух контрактов:

- `schema.d.ts` — из корневого `book.yaml` (основной backend API).
- `schema-local.d.ts` — из `book.local.yaml` (локальное расширение контракта: подписки на новые книги автора, пока не реализовано на бэкенде).

`book.local.yaml` пишется и правится руками — это черновик контракта, который со временем должен попасть в `book.yaml`.

Оба `schema*.d.ts` файла генерируются автоматически и руками не редактируются.

## Перегенерация

```bash
pnpm generate:openapi
```
